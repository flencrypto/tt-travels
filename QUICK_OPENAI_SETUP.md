# Quick Start: Configuring OpenAI API Key

## 🚀 Quick Setup (3 Steps)

### Step 1: Get Your API Key
Visit [platform.openai.com](https://platform.openai.com) → Create new secret key → Copy it

### Step 2: Configure in Settings
Navigate to **Settings** (⚙️ in navigation) → Scroll to **API Keys** section → Paste into **OpenAI API Key** field

### Step 3: Test & Save
Click **Test** button → Verify ✅ success → Click **Save API Keys**

## 🧪 Testing Your Configuration

### Individual Test
1. Enter your OpenAI API key
2. Click **Test** button next to the field
3. Wait for validation result
4. Look for green ✅ "Verified" badge

### Test All APIs
1. Configure multiple API keys
2. Click **Test All** button at top
3. See summary of all validations
4. Each service shows individual status

---

## ❓ Common Issues

### "Invalid API key format"
→ OpenAI keys must start with `sk-`

### "API key appears to be invalid (too short)"
→ Ensure you copied the complete key (40+ characters)

### "Invalid API key"
→ Key may be revoked - generate a new one

### "Rate limit exceeded"
→ Wait a few minutes and try again

## 💡 Pro Tips

1. **Set up billing alerts** in OpenAI dashboard to monitor usage
2. **Test connection** before generating multiple itineraries
3. **Monitor costs** at [platform.openai.com/usage](https://platform.openai.com/usage)
4. **Rotate keys** periodically for security
5. **Save your key** somewhere safe - you can't retrieve it from OpenAI later
